# Security / Segurança

## English
Found a security issue (for example, something that exposes API keys, recordings or the history)?
**Don't open a public issue.** Use the **"Report a vulnerability"** button in this repository's
**Security** tab (GitHub private vulnerability reporting). Only the maintainer sees the report.

## Português
Achou uma falha de segurança (por exemplo, algo que exponha chaves de API, gravações ou o histórico)?
**Não abra uma issue pública.** Use o botão **"Report a vulnerability"** na aba **Security** deste
repositório (relato privado do GitHub). Só o mantenedor vê o relato.
