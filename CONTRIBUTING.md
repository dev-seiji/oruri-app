# Contributing to Oruri / Contribuindo com o Oruri

🇺🇸 English · 🇧🇷 Português abaixo

## English

Thanks for your interest! For now, Oruri **does not accept code pull requests**.
Pull requests with code will be closed without review, with a link to this file.

**Very welcome:**
- **Bug reports**: open an issue with the Oruri version (Settings › Updates), your macOS version, the steps to reproduce, and what you expected.
- **Suggestions and ideas**: open an issue describing the problem it solves.
- Translation mistakes (English, Spanish, Portuguese, Japanese) can also be reported as issues.

Please don't paste API keys, passwords or personal dictated text in issues.

**Why no code for now?**
Oruri is a personal portfolio project, built to learn how AI tools work in a real app, so I keep the code
my own. Issues and ideas are still very welcome.

**Security issues** should not be filed as public issues: see [SECURITY.md](SECURITY.md).

## Português

Obrigado pelo interesse! Por enquanto o Oruri **não aceita pull requests de código**.
Pull requests com código serão fechados sem revisão, com um link para este arquivo.

**Muito bem-vindos:**
- **Relatos de bug**: abra uma issue com a versão do Oruri (Settings › Updates), a versão do macOS, como reproduzir e o que você esperava.
- **Sugestões e ideias**: abra uma issue contando o problema que ela resolve.
- Erros nas traduções (inglês, espanhol, português, japonês) também podem ser relatados por issue.

Não cole chaves de API, senhas nem textos pessoais ditados nas issues.

**Por que não aceito código agora?**
O Oruri é um projeto pessoal de portfólio, feito para aprender como as ferramentas de IA funcionam num app
de verdade, então o código fica só comigo. Relatos e ideias continuam muito bem-vindos.

**Falhas de segurança** não devem ir em issue pública: veja o [SECURITY.md](SECURITY.md).
